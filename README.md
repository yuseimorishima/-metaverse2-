# KOMOREBI — ここで、暮らそう。

ブラウザで遊ぶ、一人称視点の生活シミュレーションのプロトタイプです。Three.js で描いたアパートと街を、自分のペースで歩いて暮らせます。旅行予約サイト、今日の生活プラン、洗濯・掃除・学習などの家事と趣味も遊べます。旅行を含めた支払いは、ひとつのお財布から行います。

## 起動

Node.js 22.12 以降（この環境では 24.22.1）を使用します。

```sh
npm ci
npm run dev
```

開発サーバーの既定ポートは 5173 です。画面の「暮らしをはじめる」を押すとプレイできます。WebGL 対応ブラウザで動きます。PC はキーボードとマウス、タッチ端末は画面の方向ボタンとドラッグで操作します。パッケージ導入後のプレイに外部サービスや API キーは不要です。

## 暮らしの仕組み

- キッチンで水を飲む、コーヒーを淹れる。持ちものからパンやりんごを食べる。
- ベッドで翌朝 7:00 まで眠る。ソファ・読書・公園で休む。
- パソコンの在宅仕事で 1日1回 ¥2,400＋学習ボーナスを得る。体力20以上が必要。
- マーケットで食べものや豆を購入。カフェと花屋でも買い物ができる。
- 空腹・水分・体力・気分が時間と行動で変わる。昼夜で空の色・日光・照明が変わる。
- 初期所持金 ¥5,000。現実の30秒でゲーム内の1時間が進む。睡眠や仕事は時間を進める。
- 15秒ごと、行動後、一時停止時にブラウザの localStorage に自動保存。次回は「前の暮らしをつづける」で再開。保存はブラウザごとで、サーバー同期はありません。
- 右上の音符ボタンで環境音を切り替える。初期状態は消音。

## 検証

```sh
npm test           # 生活状態・旅行・街・家づくり・天気・食事と入浴・保存データのテスト（38件）
npm run build     # 本番向けビルド
npm run test:e2e   # 実ブラウザで描画・移動・食事・地図・保存復元・生活操作
```

E2E はこのクラウド環境の `/usr/bin/chromium` を使用します。他の環境では `playwright.config.js` の `executablePath` を変更するか、Playwright のブラウザを導入して指定を省略してください。

## 構成と現在の範囲

- `src/world.js`：建築、家具、街、衝突、操作対象。外部アセットを使わず形状と質感を生成し、静的メッシュを材質ごとに統合。
- `src/main.js`：一人称移動、光、画面、音、入力と保存。
- `src/life.js`：描画から独立した生活状態と行動。

この版は小さな街で生活の循環を遊べる土台です。写実的な人物・モーション・会話、店員との細かな接客、マルチプレイ、食材を自由に切るような精密な調理操作は未実装です。調理・食事・入浴は工程ごとに操作して過ごします。仕事や読書などの休憩は、操作後に時間と状態が変わる方式です。セーブはバージョン1形式です。

## 旅行予約サイトと、東京から京都・嵐山への旅

**J キー**または右上の「旅のサイト」から、旅先・宿・ゲーム内の出発日を選びます。既存セーブにも旅行状態を追加し、持ちものや暮らしは引き継ぎます。

1. 東京駅へ移動。左側の券売機で京都ゆきのきっぷを購入。
2. 右側の6号車の乗車口で E を押して新幹線に乗車。
3. 車内の窓の外には流れる風景。席で E を押すと到着まで時間を進められます。歩いて前方デッキへ進み、到着後に降車。
4. 京都駅では後方左側の嵯峨野線の案内から嵐山へ移動。
5. 嵐山では前方の渡月橋、右側の竹林、左側の温泉宿を散策。
6. 宿のフロントでチェックイン。右手の客室、左手の食事処へ。客室ではお茶、露天風呂、宿泊を体験。
7. ロビーでチェックアウトし、嵯峨嵐山→京都→新幹線→東京の順に戻れます。

旅行積立金は廃止しました。新幹線・嵯峨野線・宿・駅弁も、お財布から支払います。新規プレイはお財布 ¥5,000 から。以前のセーブに残っている旅行積立は、最初の読み込みで一度だけお財布へ合算し、切符・宿泊・持ちもの・家は引き継ぎます。

新幹線は片道 ¥14,000、嵯峨野線は片道 ¥240。宿は花伝抄 ¥22,000（2食付き）、ゲームオリジナルの「嵐山 こもれび庵」¥12,000（2食付き）、「嵐山 まちやステイ」¥6,800（素泊まり）を選べます。素泊まりの食事は夕食 ¥1,800・朝食 ¥850。これらはゲーム内の設定値で、実際の運賃・宿泊料金・サービス内容ではありません。

サイトでは本日から30日先まで予約できます。宿だけ・片道の新幹線・往復交通と宿のセットを選び、予約一覧から未使用分を全額返金で取り消せます。往復セットは新幹線の往復と嵯峨野線2回分を含み、乗車やチェックインで二重に支払いません。帰りの新幹線きっぷは京都に着くと使える状態になります。新幹線は予約日から利用でき、宿は予約当日の15時からチェックインします。

サイトの「予定に入れる」は費用の発生しない予定の保存です。予約・購入のボタンはお財布から代金を支払います。予約しても場所は変わらず、東京駅・乗車口・宿のフロントまで自分で進みます。

モデルにする宿は **京都 嵐山温泉 花伝抄**です。**館内の完全再現は未完了で、現在は仮内装です。** 公式資料への接続がネットワーク制限で拒否されており、館内写真・間取りとの照合が必要です。詳細は [資料状況](docs/hotel-reference.md) を参照してください。駅・列車・嵐山も縮尺や配置を省略したゲーム用の表現です。

旅行ロジックは `src/travel.js`、旅行先の描画は `src/travel-world.js` に分離しています。`npm test` は生活4件・旅行7件・街4件・家づくり4件・デラックス5件・食事と入浴8件・生活パターン6件。`npm run test:e2e` は生活・旅行・ドラッグ・タッチ操作・徒歩の街・家づくり・天気・自転車・調理・食事・入浴のブラウザ操作46件を検証します。

## ダウンロード版（サーバー不要）

`npm run build:portable` で、コードとスタイルをすべて含む `dist/KOMOREBI.html` を生成します。PCのChromeまたはEdgeでこのHTMLを開くとプレイできます。外部アセット・API・開発サーバーは不要です。

`node scripts/test-portable.mjs` は単一HTMLの描画、食事、東京への移動、セーブ復元、外部アセット要求がないことを検証します。この環境の管理ブラウザは `file://` の表示を禁止しているため、テストでは同じHTMLをメモリから返して実行します。実際のローカルファイルからの表示はこの環境では検証できません。

## ドラッグ操作と、広がった暮らし

画面を押したままドラッグすると見回せます。マウスを離すと回転が止まり、持ちものや案内のボタンをそのままクリックできます。マウスのロックは使いません。タッチ端末では方向ボタンを押しながら別の指で見回せます。「調べる」「持ちもの」「街」の画面ボタンもあります。

街の施設は一枚のマップ上にあります。B または「街の案内」で道案内を選んでも移動しません。方向と距離を見て、道路と入口を歩いて通ってください。M は街全体の地図です。新幹線などで旅行中の場合は、東京から街へ戻って利用します。

- 森のカフェ店内：マスターとの会話、2時間の手伝い（1日1回 ¥1,800）、トマト2個の配達（1日1回 ¥900）、コーヒー。
- 図書館：司書との会話、読書、本の整理（1日1回 ¥1,400）。
- 市民農園：最初に種3袋。種まき→水やり→ゲーム内1時間でトマト3個を収穫。追加の種3袋は ¥150。育成は他の場所にいても進み、保存されます。
- 水辺：売店で釣り竿を ¥500 で借り、桟橋で釣り。「今！」の表示中に E・Space またはボタンを押すタイミングゲームです。魚は料理に使うか、1匹 ¥300 で売れます。
- 見晴らしの丘：1日1枚の風景写真。直近の写真を保存し、街の案内から見返せます。
- 自宅のキッチン：トマト1個と魚またはパン1個で、切る・火にかける・盛りつける工程を操作します。I の持ちものから、ひと口ずつ食べられます。

達成した遊びは7種類の「暮らしの思い出」として記録。既存セーブには街の状態を追加し、所持金・旅行・持ちものを引き継ぎます。

## 土地からつくる、自分の家

街を約240×200mの連続したマップへ変更しました。カフェ・図書館・店・農園・水辺・丘・住宅地は道でつながっています。地域の境界を歩いて越えると場所の表示だけが変わり、カメラや位置を切り替えません。施設から道路へもそのまま歩いて帰れます。

H または右上「家づくり」で、南側の住宅地を確認できます。住まい相談所、各区画の看板、家具店でも E で相談できます。

- 土地3区画：楓 ¥3,500、中央 ¥6,000、朝日 ¥9,000。複数所有も可能。
- 家3種類：木のコテージ ¥1,800、モダンハウス ¥2,600、和風平屋 ¥3,200。購入した土地の北側（道路側）に立って建築してください。
- 外壁4色・屋根3色・床3色：変更は各 ¥100。
- 家具12種類：ベッド、ソファ、テーブル、キッチン、仕事の机、観葉植物、ライト、ラグ、シャワー、テレビ、本棚、水槽。購入後は収納へ。
- 家の近くで H →「家具を配置・移動する」。マスを選んで置き、90度回転・移動・収納への片づけができます。1軒12個まで。入口・家の範囲外・他の家具・プレイヤー自身と重なる位置は避けます（ラグは家具と重ねられます）。
- 自分で置いたベッドで睡眠、キッチンで料理、机で在宅仕事、ソファで休憩ができます。

土地・建築・家具・色・配置は自動保存されます。価格は現実の不動産価格ではなくゲーム内の設定です。最初の所持金だけでは建築まで足りないので、仕事や配達の報酬を暮らしづくりに使ってください。以前の独立した施設内のセーブは、初回読み込み時に新しい街の同じ施設の座標へ一度だけ変換します。


## デラックス版の暮らし

- 空のグラデーション、動く雲、夕方の光、夜空の星、雨粒と水たまりを追加。晴れ・曇り・雨がゲーム内の日付で変わり、L で今日と明日の天気・気温を見られます。
- 木材・塗り壁・舗装に、物の大きさに合わせて繰り返す質感を使用。地面に隠れていた道路も修正。家具の角を丸め、室内の間接光と夜の街灯を調整。近くの照明を優先し、描画性能と画面サイズに合わせて解像度を自動調整します。商店街に花壇・日よけ・横断歩道を追加しました。
- 住民が歩道を歩き、車が通りを走ります。車は近くのプレイヤーの手前で停車します。車との衝突で体力が減る仕組みはありません。

- 傘は L から開閉します。屋外では画面に傘が現れ、雨による清潔さの追加低下を防ぎます。室内では表示しません。自転車に乗ると傘をしまい、降車してから使えます。
- 新しい「清潔さ」は時間とともに減少。街の西側の銭湯「こもれび湯」は ¥350で受け付けし、洗う・流す・湯船へ歩く・つかる・拭く工程で清潔さと体力・気分を回復します。入口まで歩き、E で入浴を選びます。M の地図から道案内できます。
- 自宅用シャワー ¥650、テレビ ¥900、本棚 ¥280、水槽 ¥600 を家具カタログへ追加。H から購入・配置し、近くで E を押すと使えます。シャワーは体を洗い、流して拭く工程で清潔さを回復。他の3種類は時間を過ごして体力と気分を回復します。映像・本の本文・魚の飼育は未実装です。
- 徒歩で1日300m歩いたら、L で街歩きチャレンジの報酬 ¥700 を受け取れます。自転車で走った距離は含まず、報酬は1日1回です。
- 天気は日付から計算し、清潔さ・自転車・傘・徒歩記録は自動保存。以前のセーブは、お金・持ちもの・土地・家・家具を保ったまま新しい状態を追加します。


## 飛ばさずに過ごす、食事と入浴

料理・食事・飲み物・お風呂は、一度のクリックで完了する方式から変更しました。目の前に料理や食器、手元の動きが表示され、進行中も画面ドラッグで見回せます。

- 自宅の調理：キッチンで E →「野菜のプレートを作る」。野菜を切る→火にかける→盛りつける工程を、E または体験カードのボタンで操作。完成してから持ちものに1皿入ります。
- 食事：I で料理・パン・りんごを選び、E または「ひと口食べる」。かみ終わると料理が少し減り、その分だけ空腹などが回復します。料理は6口、パン・りんごは4口。最初の一口も、待たずに回復することはありません。
- 飲み物：自宅のコーヒー・水、カフェのコーヒー、宿のお茶は3口に分けて飲みます。新幹線の駅弁も食事の工程を使います。
- 入浴：銭湯は受付後に洗い場まで歩き、3回洗う→シャワーで流す→案内に従って湯船まで歩く→お湯につかる→タオルで拭く。客室の露天風呂も同じ工程です。自宅シャワーは開いた正面からブースへ歩いて入り、洗う→流す→拭く。湯船では目線がゆっくり下がります。
- 「いったん休む・席を立つ」で途中から離れられます。「続きを過ごす」または I から再開。カフェやお風呂は元の場所へ戻ってください。リロード後は中断状態で復元し、勝手に食べ終わったり、二重に食材や料金を使ったりしません。
- 食材・料理・料金は開始時に1回だけ使用します。「片づけて終える」で残りを取りやめた場合は返却しません。完了前の報酬や残りの回復量は得られません。

## 今日の予定と、増えた生活パターン

P または右上「今日の予定」で、ゆっくり暮らす日／仕事と家事の日／外で過ごす日／趣味と学びの日／旅を楽しむ日を選べます。予定を変えても行動は強制されません。食事・入浴・仕事・収穫・釣り・写真・徒歩など、実際に行ったことを記録します。その日の目標を3つ達成して振り返ると、1日1回、気分が12回復します。最近7日分の暮らしも残ります。

- 掃除：自宅の部屋で P →「家を掃除する」。床を掃く→棚を拭く→部屋を整える3工程で気分を回復します。
- ストレッチ：自宅・公園・水辺・農園・丘・宿の客室で、肩を回す→背中を伸ばす→深呼吸。体力と気分が少し回復します。
- 学習：自宅・図書館・カフェ・宿の客室で、本を開く→読む→メモ。1日1回、学習の積み重ねが3増えます。在宅仕事の報酬は ¥2,400＋学習値×¥5、最大 ¥2,900 です。
- 家事と趣味も E または体験カードで3工程を進めます。初期設定の目安は約20秒で、食事と同じペース設定を使います。
- 洗濯：こもれび湯の入口から右奥のランドリーへ歩き、E。¥100で洗濯・乾燥が始まり、ゲーム内90分で終了。運転中は街で別のことをして過ごし、同じ洗濯機の前で受け取ります。開始受付は6:00〜23:00。運転・終了待ちの状態も自動保存します。

新しい計画・家事・学習は `src/daily.js` と `src/daily-ui.js`、旅行予約サイトは `src/travel-ui.js` で管理します。旅行データは旧形式も読み込み、お財布へ一度だけ統合する形式に更新します。GitHub の `main` には起動用ソースとテストを保存し、`komorebi-site` には公開向けの単一HTMLを置きます。

## 宿の3段階と、デラックスツインの再現状況

J の旅行サイトで、嵐山の宿3種類を「1 ベーシック／2 スタンダード／3 デラックス」の順に比較・絞り込みできます。予約一覧にも客室名を表示し、選択した宿の名前をフロントに反映します。料金と食事条件、既存の予約・セーブは引き継ぎます。このグレードはゲーム内の区分で、実在施設の公式ランクではありません。

ベーシックは「嵐山 まちやステイ」のベッドツインルーム、スタンダードは「嵐山 こもれび庵」の和のツインルーム、デラックスは「京都 嵐山温泉 花伝抄」のデラックスツインを再現対象としています。

**デラックスツインの内装再現は資料照合待ちです。** 公式サイトは通信制限で取得できず、客室写真・間取りを確認できていません。現在の客室モデルを実物の再現として扱わないでください。詳細と必要資料は [資料状況](docs/hotel-reference.md) にまとめています。最新の追加依頼に合わせ、資料待ちの客室はその状態を明記し、他地域にはゲームオリジナルの街と宿を追加します。

## 歩いて巡る、新しい旅先

J の旅行サイトで行き先を選び、日帰りの往復券または往復交通＋宿を予約できます。東京駅の「観光路線」乗車口まで歩いて E。旅先でも駅・カフェ・売店・宿・撮影スポット・スタンプ・休憩所が道でつながっています。宿から出ると、入ったときの入口へ戻ります。

カフェは 7:00〜21:00、ランチプレート ¥700 をひと口ずつ食べられます。写真とスタンプは各地で1日1回記録し、J の予約画面で確認できます。帰りは宿をチェックアウトし、街の駅で E。未使用の観光路線は片道分ずつ取消・返金できます。街の配置・観光路線・追加した宿はゲームオリジナルで、実際の交通経路・運賃や施設を再現したものではありません。

追加済み：鎌倉（海辺・参道、なぎさゲストハウス／シーサイドテラス）。

箱根：湖を囲む山々、鳥居とギャラリーを眺めながら歩く温泉の街。 箱根 湖畔のこもれび／箱根 みずき温泉邸。

日光：杉並木の参道、森のお堂と滝を歩いて巡る静かな旅。 日光 すぎの木ロッジ／日光 森灯りの宿。

奈良：鹿が過ごす公園、お堂と古都の道をゆったり歩く街。 奈良 こみち町家ステイ／奈良 若葉ガーデンホテル。

大阪：川辺の街並み、展望塔とにぎわう横丁を歩いて楽しむ街。 大阪 かわまちステイ／大阪 リバースカイホテル。

神戸：港の塔、停泊する船と海辺のプロムナードを巡る街。 神戸 ハーバーテラス／神戸 オーシャンレジデンス。

## 宿を先に予約した後の列車移動

箱根などの宿だけを予約済みでも、J の「往復列車の予約」で乗車券だけ追加できます。宿の予約・支払い・持ちものは引き継ぎます。新しい地域の乗車券と京都の新幹線の乗車券は別に管理します。

東京駅では道案内をたどり、観光路線または通常の6号車の乗車口で E → 行き先を選んで乗車します。券売機でも各地域への往復券を購入できます。M に東京駅の地図を追加しました。未来の DAY の乗車券は当日から利用でき、乗車画面に利用日を表示します。交通・宿の二重払いと、予約画面から駅の中をワープする移動は行いません。

## 列車を選び、車内でも旅を楽しむ

J の旅行サイトで、追加した6地域への列車を4種類から選べます。窓側・通路側の希望も指定できます。従来の東京〜京都の新幹線も利用できます。新しい列車名・経路・駅・料金・所要時間はゲーム用の設定です。

| 列車 | 車内と旅の特徴 |
| --- | --- |
| 街めぐり普通列車 | お手頃な運賃、ベンチ席・つり革、途中の駅の案内 |
| こもれび特急 | 標準運賃、2列ずつの座席、目的地へ直接向かう旅 |
| 展望観光列車 | 大きな窓と展望ラウンジ、景色を楽しむ長めの移動 |
| プレミアム特急 | クリーム色のソファ席、木目・真鍮・カーテンと間接照明、短めの移動 |

未使用の往復券は、J で別の列車・座席希望へ変更できます。支払う／返金する金額は運賃の差額だけです。宿の予約は保ちます。乗車後の券は列車を変更できませんが、同じ列車の復路をそのまま利用できます。以前に購入した乗車券は、標準の特急として追加支払いなしで引き継ぎます。

駅で乗車すると車内へ入ります。車内ではドラッグで見回し、「車窓を見る」で目線を窓／通路へ滑らかに切り替えられます。「10分くつろぐ」、車窓を眺めながら到着まで過ごす操作、駅弁 ¥1,200 を一口ずつ食べる体験を選べます。移動は車内で自動でも進み、途中で保存・再開できます。到着後は「到着駅で降りる」、または前方デッキの E で降車します。スマホで食事中は、食事の画面が読みやすいように乗車案内を一時的にたたみます。

宿を先に予約していても、列車だけ追加できます。到着が日付をまたいだ場合は、該当する未使用の宿泊予約を到着日へ引き継ぎ、二重に宿泊代を請求しません。

プレミアム特急は、幅広いソファ席・足置き・クッション、木目のパネル、真鍮の縁取り、カーテン、天井の照明へ改装しました。テーブルにはカップや端末などの小物を置き、後方に飾り棚を設けています。車幅と通路の余裕を広げ、旧内装の家具と重なるセーブ位置は通路へ調整して再開します。運賃・乗車券・宿の予約は引き継ぎます。
