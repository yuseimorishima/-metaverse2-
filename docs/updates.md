# 旅先の追加記録

完成した行き先ごとにソースと公開用HTMLをGitHubへ保存します。

## 鎌倉

- 海辺・参道・カフェ・売店・写真・スタンプ・休憩場所を徒歩で接続。
- なぎさゲストハウスとシーサイドテラスを追加。
- 旅行サイトの行き先選択、観光路線の往復券・片道ごとの返金を実装。
- 徒歩マップ、宿の入口への帰還、旅先の食事・天候・セーブに対応。

追加の街・宿・観光路線はゲームオリジナルです。花伝抄デラックスツインは引き続き資料照合待ちです。

## 宿の予約後に列車へ乗れない問題を修正

宿だけを予約すると往復交通を追加できなかった条件を修正。乗車券だけの購入で宿・旅の予定・既存の京都ゆき乗車券を保持します。券売機に各行き先を追加し、通常の乗車口でも予約した街へ乗車できます。東京駅の徒歩マップ・乗車口への道案内・予約日の表示を追加しました。

## 列車の種類と旅行体験を拡充

普通列車・特急・展望観光列車・プレミアム特急を追加。車内の座席・窓・ラウンジ、運賃と所要時間、経由案内を分けました。旅行サイトと駅で列車と座席希望を選べ、未使用の往復券は差額で変更できます。

追加地域への移動も車内で過ごしてから降車する流れへ更新。残り時間と到着案内、車窓ボタン、10分休憩、到着後の降車ボタンを追加しました。車内の駅弁は食事の工程を維持し、スマホでは食事画面の重なりを解消しています。移動途中の保存、旧乗車券、復路券、未使用の宿泊予約を引き継ぎます。
