# 旅先の追加記録

完成した行き先ごとにソースと公開用HTMLをGitHubへ保存します。

## 鎌倉

- 海辺・参道・カフェ・売店・写真・スタンプ・休憩場所を徒歩で接続。
- なぎさゲストハウスとシーサイドテラスを追加。
- 旅行サイトの行き先選択、観光路線の往復券・片道ごとの返金を実装。
- 徒歩マップ、宿の入口への帰還、旅先の食事・天候・セーブに対応。

追加の街・宿・観光路線はゲームオリジナルです。花伝抄デラックスツインは引き続き資料照合待ちです。

## 箱根

- 湖を囲む山々、鳥居とギャラリーを眺めながら歩く温泉の街。
- 箱根 湖畔のこもれび（湖を望むツイン）／箱根 みずき温泉邸（湖畔の温泉スイート）を追加。
- 徒歩の施設接続・宿泊・往復交通・返金・保存を確認して個別に更新。

## 日光

- 杉並木の参道、森のお堂と滝を歩いて巡る静かな旅。
- 日光 すぎの木ロッジ（森のツインルーム）／日光 森灯りの宿（木立の和洋スイート）を追加。
- 徒歩の施設接続・宿泊・往復交通・返金・保存を確認して個別に更新。
